期中報告2026-08-26Dyn-VGGT

把相機 pose
從場景運動裡拆出來

VGGT 在動態場景與內視鏡影像上，唯一明顯落後的指標是相機 pose。根因是 pose 與物體／組織的運動在 aggregator 的 global attention 中耦合。本報告從三個正交的軸解除這個耦合，全程純前饋、不做 test-time optimization、不動幾何頭。

① Motion Gate前向 · attention bias
② Motion Loss監督 · 剛性 warp 約束
③ Temporal時序 · 時間軸 attention
問題定位§1

ProblemVGGT 是什麼，弱在哪裡

VGGT 是前饋式多視角幾何 transformer：S 張影像一次前向，同時輸出相機參數、depth、point map。不需要 per-scene 最佳化。

{It}t=1..S⟶{ĝt}, {D̂t}, {X̂t}

pose encoding 採 absT_quaR_FoV，9 維，以第一幀為世界原點：
gt = [ t ∈ ℝ³ | q ∈ ℝ⁴ | fov ∈ ℝ² ]

觀察到的弱項

深度領先，pose 落後

depth 在動態場景已具競爭力；輸的是相機軌跡。內視鏡場景更嚴重——組織會變形、器械會移動、鏡頭高光跟著相機走。

刻意的範圍限制

只做 pose，且純前饋

不輸出 scene flow、不改幾何表示、不做 test-time optimization。depth head 全程凍結，保住既有的深度品質。

問題定位 · 耦合§1.4

The couplingcamera token 把運動平均了進來

在 global attention 裡，所有幀的所有 token 攤平一起做 attention。每一幀的 camera token 會 attend 到所有幀的所有 patch——包含正在移動的那些。

A = softmax(QK⊤√d + B) , oi = ∑j Aij vj
o[ct] = ∑s=1..S ∑j=1..Ppatch A[ct, xs(j)] · v(xs(j)) ← j 跑遍所有 patch，靜態與動態一視同仁

原版 VGGT 中 B ≡ 0。動態物的運動被平均進 camera token → 送進 camera head → pose 被污染。

為什麼 loss 端的 mask 救不了：在 loss 端屏蔽動態區只是「不去罰它」，pose 在前向時就已經被污染了。屏蔽必須搬到 attention 端。

方法總覽§2–4

Overview三個正交的軸，打同一個耦合

① 前向 · enable_gate

Motion Gate

aggregator 中段預測 per-patch 動態 logit g，在後段 global attention 對 camera/register 的 query 列加負 attention bias，讓 camera token 結構性地只聚合靜態 patch。

② 監督 · loss.static_photo

Motion Loss

剛性 warp 只在靜態區成立。用 GT depth 反投影、以預測 pose warp 到鄰幀，RGB 必須匹配——造出獨立於 GT pose 重參數化的光度訊號。

③ 時序 · enable_temporal

Temporal + Smooth

補上 VGGT 缺的純時間軸 attention（每個空間位置 attend 自己的 S 幀），並對預測軌跡的二階不連續加正則。

三者共同的性質

  • Identity warm-start：初始化時前向與 pretrained VGGT-1B 逐位元相同。
  • patch↔patch attention 一字不改：depth/point head 的輸入特徵不變。
  • 純前饋：推論成本 ≈ 原 VGGT，額外顯存 ≈ 0。

兩條應用線

  • 通用動態場景（Sintel / PointOdyssey / TartanAir / Waymo / Spring）：有動態標註，gate 走 BCE 監督。
  • 醫學內視鏡（SCARED / C3VD / 私人資料）：沒有動態標註，gate 改由 pose loss 當老師。本報告主線

貢獻 ① Motion Gate§2.1

Contribution ①中段 Gate Predictor

門控要在聚合進行中就用到動態訊號，但動態訊號通常要讀最終特徵才得到——雞生蛋。解法是在 aggregator 中段插一個輕量 MLP。

觸發點
第 k = 7 個 aa-block 完成後（約全深度 1/3）
輸入
中段的 contextualized patch token，切掉 camera+register
輸出
每 patch 一個動態 logit；σ(g) 即免費的 dynamic mask

為什麼放中段：太早特徵未成熟，太晚則後面沒幾個 global block 可被清洗。1/3 是「特徵夠成熟」與「後段仍有 2/3 block 可門控」的平衡。

gt,j = W2 GELU(W1 LN(x(k)t,j))

W1 ∈ ℝ(C/4)×C  ·  W2 ∈ ℝ1×(C/4)  ·  C = 1024

關鍵設計

末層 zero-init

W2 = 0 → 訓練第 0 步 g ≡ 0 → bias ≡ 0 → 前向逐位元等於 pretrained VGGT。門控隨訓練漸進通電。

解析度天然對齊：g 在 patch 格上，而 attention 的 key 本來就是 patch token → bias 直接套，零插值。

The gating bias只壓 camera query 那幾列

B[i, j] = b(gj)i ∈ camera/register queries，j ∈ patch keys 0其餘所有位置（patch↔patch 完全不動）
b(g) = min( 0 ,  softplus(0) − softplus(g) ) = min( 0 ,  ln 2 − ln(1 + eg) )
性質 1

−softplus(g) = ln σ(−g) = ln P(static)

貢獻 ① · 醫學線變體§2.3

No labels, no teacher沒有動態標註時，讓 pose loss 當老師

通用線上 g 由 GT mask 的 BCE 監督，bias 路徑 detach。但 SCARED / C3VD 沒有動態標註——detach 加上沒有 Lgate，門控完全不可訓練。醫學線因此打開兩個旋鈕。

(a) gate_pose_grad = True

移除 detach，讓 Lcam 直接訓練 gate：

∂Lcam∂gj = ∂Lcam∂bj · b′(gj) , b′(g) = −σ(g)g > 00g < 0

語意從「哪裡在動」變成「哪些 patch 對 pose 有害」——更弱，但在無標註域上唯一可得的訊號。

(b) gate_leaky = 0.1

clamp 在 g<0 整段是平的，梯度恆為 0——被推下去的 patch 再也回不來（dying-ReLU 式吸收態）：

bλ(g) = xx ≤ 0λxx > 0 , x = ln 2 − softplus(g)

代價：有信心的靜態 patch 最多被放大 λ ln 2 ≈ 0.07。分界用 x ≤ 0 而非 <，讓 zero-init 的起點走非 leaky 分支。

誠實揭露

這是方法上的實質差異，不宜與「有標註的 gate」混為一談。醫學線的 gate 是否收斂到有意義的東西、或只是退化成一個 attention 溫度旋鈕，目前是開放問題——gate_g_median 與 gate_frac_active 兩個 log 就是為了監控這件事。

貢獻 ① · 實作§2.4

Memoryattention 拆兩條 path，顯存成本 ≈ 0

把整個 [N,N]（N=S·P）的浮點 mask 交給 F.scaled_dot_product_attention，會讓 flash kernel fallback 到 memory-heavy 的 math backend → 顯存暴增 O(N²)。

正解是依 query 拆兩條路徑——只有帶 bias 的那條需要放棄 flash，而它極小。

Attn(Qpatch, K, V)
Path 1 — S·Ppatch 個 query，無 bias，走 flash

Attn(Qspecial, K, V ; B)
Path 2 — 只有 5S 個 query，帶 bias，小 op
拆分必須逐幀 gather

frame-interleaved 的代價

q.view(B,H,S,P,D)[:,:,:,:5]  → special
q.view(B,H,S,P,D)[:,:,:,5:]  → patch

key 端的 bias 也照 interleaved 順序組：每幀的 patch 欄位填 b(g)、special 欄位填 0。

曾經踩過的坑

早期版本用 q[:, :, :5S]。因為 5S ≪ P，那些索引全落在 frame 1 內 → 只有 frame 1 的 camera token 被門控，其餘幀完全沒作用。修正前的所有 gate 數字皆已作廢。

效果：camera token 在後 2/3 的 global block 中結構性地只聚合靜態 patch，而 patch↔patch attention 一字不改 → 深度品質完全保留。

貢獻 ① · 監督（通用線）§2.5

Labels標籤的語義決定跨域能不能活

Lgate = BCE( σ(g) , m*patch )

m*patch = pixel 級硬 mask 經 AvgPool14×14 後的軟機率。此路徑不 detach，梯度回流 predictor。

(a) instance × GT scene-flow — 訓練用

以 GT world track 判斷每個 instance 連通塊是否位移，動則整塊填滿。靜態世界點位移恆為 0，沒有門檻的快慢兩難。

(b) 幾何光流殘差 — 測試／跨域用

fcam(u) = π( Pt+1Pt−1 π−1(u, Dt) ) − u
mgeo = 1[ ‖fgt − fcam‖ > max(τabs, α‖fgt‖) ]

相對門檻 α‖fgt‖ 是必要的：純絕對門檻在高速鏡頭序列會整片灌爆。

被否決的做法

外觀 mask ≠ 運動 mask

PointOdyssey 原生的 masks/ 是逐 instance 的外觀分割——連牆、地板、靜止的前景都被標。拿它監督，門控學到的是「這個資料集的室內外觀 → 動態」，換域必崩。

跨域證據（只訓 gate predictor）

標籤PO AUCSintel AUC
RAFT flow-residual0.9840.584 崩
instance × scene-flow0.9260.767

標籤在兩個域是同一個物理量（世界真的在動），跨域即不再崩。Sintel AUC +0.183，PO 只掉 0.058。

判讀 gate 品質一律用 AUC / F1，不看 BCE：pool 後的軟標籤在 boundary patch 有不可約的 floor，val BCE 會看似 overfit 卻與高 AUC 並存。

貢獻 ② Motion Loss§3

Contribution ②剛性 warp 只在靜態區成立

Lcam 直接拿預測的 pose encoding 對 GT 算 L1，不經像素——pose 因此只有「GT 的一個重參數化」這一個訊號。物理約束提供了獨立的第二個訊號。

û′ = π( K [ R̂t→t+1 ( K−1u · Dgtt(u) ) + t̂t→t+1 ] )
Lstatic_photo = 1|𝒮t| ∑u ∈ 𝒮t ρδ( It(u) − It+1(û′) ) ρδ = Huber, δ = 0.1

有效像素集合 𝒮t

  • GT 靜態區：m*(u) < τdyn
  • GT depth 有效
  • 重投影落在影像界內
  • 遮擋防護：把 t+1 的 motion mask 也 warp 過去，落在動態區則丟棄

梯度只進預測 extrinsics

GT depth、內參、影像皆為常數，梯度經 grid_sample 的取樣 grid 回流到 pose。depth head 完全不碰，維持「不動幾何頭」的 scope。

現況 · 誠實標註

通用線上是負結果

在 Sintel 上比 warm-start 起點更差，且單調惡化。醫學線未使用此 loss（config 中 static_photo: null）。列為「已試、方向為負、待重新設計」，不當賣點。

貢獻 ③ · Camera-Smooth Loss§4.2

Trajectory prior罰預測軌跡的加速度

困難序列上觀察到明顯的軌跡「跳動」（native VGGT-1B 也有）。加一個只作用在網路自身輸出的平滑先驗——類似 MonST3R 的 trajectory smoothness，但作為訓練 loss 而非 test-time 項。不使用 GT pose。

速度（一階，除以真實時間間隔）
vTs = t̂s+1 − t̂sΔts , vRs = q̃s+1 − q̃sΔts

加速度（二階，預設）
as = vs+1 − vs
Lsmooth = 1n ∑i=1..n γ n−i [ wT · |aT,(i)| + wR · |aR,(i)| ]
n = 4 個 refine stage · γ = 0.6 · wT = wR = 1
細節 1

Δt 正規化

訓練 clip 的抽幀間距不規則、可能重複。用真實時序 index 算 ΔT/Δt，Δt=0 的 pair 排除。

細節 2

四元數半球對齊

q 與 −q 是同一旋轉；差分前先逐幀 sign-fix，否則 sign flip 會被誤當成巨大的旋轉跳動。

細節 3

FoV 不平滑

與觀察到的跳動症狀無關。需 S ≥ 3，故取樣張數下界取 4。

機制 vs 目標：temporal attention 是機制（讓網路能跨幀看），camera_smooth 是目標（要求輸出時序連貫）。兩者可獨立開關，但目前的實驗把它們綁在同一個 arm —— 因子未拆解

評測協定 · Pose§8.1

Metrics兩種 ATE，不可互換

(a) 全序列 ATE — evo，Sintel / C3VD 用

把預測外參轉成相機中心軌跡，與 GT 做 Sim(3) 對齊後算 RMSE：

(s*, R*, t*) = argmin ∑i ‖s R p̂i + t − pi‖²

ATE = √ 1N ∑i ‖s*R*p̂i + t* − pi‖²

同時報 RPE（delta = 1 frame，all pairs）與 ate_rel = ATE ÷ 軌跡 bbox 對角線，讓不同尺度的序列可比。

為什麼 SCARED 不報這個

VGGT 單次前向上限約 80 幀，長序列須用重疊 chunk + 逐接縫 Umeyama Sim(3) 拼接。實測拼接誤差讓 ATE 擺動 −1% ~ +32%，訊號被拼接本身淹沒。
→ SCARED 只報 snippet ATE。這是選擇不估，不是估錯。

(b) Snippet ATE — AF-SfMLearner 協定，SCARED 用

對每個長度 n=5 的滑動窗，把窗內位姿表示到窗首座標系，錨定後擬合單一 scale：

xj = ( Ci−1Cj )[:3,3] , s = ∑j ⟨xj, x̂′j⟩∑j ‖x̂′j‖²
ATEsnippet = 1n √∑j ‖s x̂′j − xj‖²

分母是 n 不是 √n——這不是筆誤，是 AF 原始碼的定義；要讓數字可與其表格對比就必須照抄。窗的枚舉也照抄：尾端的窗被截斷而非丟棄，共 S−2 個窗。

chunk 長度是預測的一部分

chunk 64 的每個窗有 64 幀 context，chunk 5 只有 5 幀（更貼近單目設定）。算指標的方式相同但預測不同，不可互相取代，必須分開記錄。

評測協定 · Depth 與無 GT 資料§8.2–8.3

Metrics對齊方式決定數字能不能比

Depth：先對齊，再算指標

afsfm — per-frame 中位數縮放，1 DOF
st = median(Dgtt)median(D̂t) 有效範圍 (10⁻², 150] mm

monst3r (lad2) — 全序列共同 scale + shift，2 DOF
(s*, b*) = argmin ∑ |s D̂ + b − D|
AbsRel = 1|ℳ| ∑ |D̂ − D|D , δk = frac[ max(D̂/D, D/D̂) < 1.25k ]

中位數必須用 np.median 語意（偶數取中間兩者平均）；torch.median 取較小者，數字會與參考實作對不上。

最重要的讀表提醒

輸入張數是隱藏變因

發表的醫學表格幾乎都是單目。零樣本 VGGT-1B 光靠 multi-view 就把 AbsRel 從 0.0758 → 0.0488——排名有很大一部分是輸入設定決定的。每張表都必須標註輸入。

無 GT 資料：Warp PSNR（自洽性）

私人資料沒有標定、沒有 GT，因此沒有精度指標。改量 depth 與 pose 合不合得起來：

Îdst(u) = Isrc( π( Tdst→src π−1(u, D̂dst(u)) ) )

另報 PSNRno spec：排除飽和高光（任一通道 ≥ 250/255）。內視鏡光源黏在鏡頭上，高光跟著相機動，幾何 warp 原理上重現不了它。

這不是精度指標 只是自洽性，且相對 VGGT 自身的 depth scale 定義，與其他模型不可比。

限制與缺口§10

What we cannot claim yet報告必須揭露的七件事

01 · 敘事

「最好的版本」沒有單一答案

選 ckpt 的 val ATE 選出 wide，test 上卻是 smooth_temporal 較好。報告要先決定用哪個指標敘事。

02 · 歸因

因子未拆解

smooth_temporal 同時開了 temporal 解凍與 Lsmooth；wide 與它的差是取樣而非架構。

03 · 對照

輸入張數混淆

vanilla(12) 與 b16(16) 張數不同，兩者之差不是純架構效果。

04 · 機制

醫學線的 gate 沒有標籤

靠 pose loss 訓練，語意變成「哪些 patch 對 pose 有害」。是否收斂到有意義的東西未驗證。

05 · 可比性

SCARED 沒有全序列 evo ATE

拼接誤差 −1% ~ +32%，EndoSfM3D 系的 pose 欄填不了。

06 · 定位

成本軸完全沒有資料

本方法是單次前饋（秒級），MonST3R 是 test-time optimization（分鐘級／序列）。wall-clock / VRAM / 是否需 per-scene 最佳化是核心宣稱，但待補。

07 · 訓練完整性

兩個 run 沒跑完

b16_gg 在 ep8 被中斷，其 best 是 8-epoch 產物；C3VD 在 ep6 之後暫停。

另：貢獻 ② 在通用線是負結果、醫學線未用；通用線（Sintel）沒有 held-out，且單次比較的雜訊門檻高達 16.9%（2σ）。

結論Novelty

One sentence三個正交的軸，同一個耦合

前向上，用 aggregator 中段的輕量 gate 在 global attention 裡讓 camera token 結構性地只聚合靜態 patch——並在無標註的內視鏡域改由 pose loss 當老師； 監督上，用「剛性 warp 只在靜態區成立」造出獨立於 GT pose 重參數化的光度訊號； 時序上，補足 VGGT 缺失的純時間軸 attention 與軌跡連貫性目標。

三者皆為 identity warm-start、皆不動幾何頭——在保留深度品質的前提下，純前饋地拿回動態／形變場景的相機 pose。
