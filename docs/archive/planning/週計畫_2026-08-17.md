## 🔬 數據量級問題的診斷順序

上週醫學影像數字量級不對，可能來自三個地方：**評估標準／harness 有問題**、**模型沒微調（domain gap）**、**架構問題**。
以下按「最便宜且最能區分」的順序做，不要跳著查：

**第 1 層：harness 還是資料？（最便宜，優先做）**
用**同一支評估腳本、同一個 checkpoint**，去跑一個你已經知道正確答案的自然影像序列（Sintel 主表）。
- 自然影像數字也不對 → 問題在**評估腳本本身**，跟醫學影像無關。往下查 scale alignment、單位、pose 慣例。
- 自然影像數字正常 → 評估腳本是好的，問題在醫學影像這一側。進入第 2 層。

**第 2 層：domain gap 還是架構？**
拿**未微調的 pretrained VGGT** 跑同一批醫學影像。
- baseline 也一樣爛 → 是 **domain gap**，符合預期，微調就是解方（不是 bug）。
- baseline 正常但你的 checkpoint 爛 → 是**你的改動壞了東西**，回去查 gate 分支或 flag 是否污染了 base 行為。

**第 3 層：量級問題的常見具體原因（前兩層定位到之後才查）**
- **scale alignment**：pose 評估是否做了 sim3 對齊？單目沒有絕對尺度，少做這步 ATE 會直接大一個量級
- **單位**：深度是 mm 還是 m；醫學影像常用 mm，差 1000 倍剛好就是「量級」問題
- **intrinsics**：內視鏡的 FOV 與鏡頭畸變跟自然影像差很多，內參錯會讓所有幾何量崩掉
- **座標慣例**：camera-to-world vs world-to-camera 弄反

> 停損：4 小時內若三層都沒定位到，改用最小可信子集（單一短序列）重跑，先讓報告有數字，根因記錄下來下週處理。

## 🧭 Gate 監督策略：本週要收斂的架構問題

因為醫學影像**沒有 dynamic mask GT**，「gate 之後還要不要用 loss 去優化」從一個 nice-to-have 的消融，變成**決定醫學影像微調怎麼做的前置決策**。

需要釐清的核心事實：gate bias 走的是 `−softplus(g)` 加在 camera query row 上，這條路徑**本身是可微的**。也就是說即使完全不加 BCE，只要 gate 沒被 freeze／detach，**pose loss 的梯度本來就會流回 GatePredictor**。所以問題不是「有沒有梯度」，而是「**要不要繼續給它標籤監督**」。

三個候選方案，本週要選一個並給出證據：

| 方案 | 做法 | 適用性 |
|---|---|---|
| **A. Freeze** | S0 訓好的 gate predictor 凍結，只微調其餘部分 | 最安全，避免醫學域上 gate 亂飄；但 gate 完全不適應新域 |
| **B. 偽標籤監督** | 用幾何 residual 造偽標籤，繼續 BCE | 有標籤訊號，但偽標籤在醫學域的可靠度未知，過往經驗顯示這類標籤脆弱 |
| **C. 純下游梯度** | 拿掉 BCE，讓 pose loss 自己教 gate | 不需要任何標籤，最貼合醫學場景；風險是 gate 可能退化成無意義的 attention 調節 |

**要回答的問題：gate predictor 在 S0 之後的訓練到底還有沒有在進步？**

驗證方式（一律用 **AUC/F1，不要用 BCE**——BCE 用 soft pooled label，boundary patch 有不可約 floor，會看似 overfit 但與高 AUC 並存）：
1. 在**自然影像 held-out**（Sintel + `m_geo`）上，量測 gate AUC 隨微調步數的變化。這是唯一有 GT 可量的地方。
2. AUC 在微調中**上升** → gate 還在學，方案 B/C 有效
3. AUC **持平** → gate 已收斂，方案 A（freeze）就夠，可以省下複雜度
4. AUC **下降** → 醫學微調正在破壞 gate（catastrophic forgetting），必須 freeze 或加正則
5. 醫學影像上沒有 GT，只能做**定性 overlay**（σ(g) 疊在影像上）佐證

> 這個結果同時是 CVPR 那條線的一個消融實驗，不是只為期中報告服務——「gate 需不需要顯式監督」本身就是方法的一個賣點。

## ⚠️ 本週最大風險

**醫學影像沒有 dynamic mask GT（已確認）**，這帶來兩個連鎖後果：

1. **訓練側**：BCE gate loss 在醫學域無標籤可用 → 必須在 A/B/C 三個方案中選一個（見上方「Gate 監督策略」）。這是本週要收斂的架構決策，不是可以拖到下週的細節。
2. **評估側**：醫學影像上**無法量測 gate AUC/F1**。唯一有 GT 的量測點是自然影像 held-out（Sintel + `m_geo`），醫學域只能做定性 overlay。這個限制要在報告裡誠實說明，不要假裝有數字。

**次要風險**：若模態是內視鏡／腹腔鏡（低視差），過往「低視差序列上任何 flow loss 都無效」的結論很可能直接命中，方法敘事需相應調整——此時 gate 的價值主張要從「改善 pose」轉向別的軸線。

## 🧩 方法單薄問題：第二個 contribution 入口

**現況**：靜態重投影 loss 推不動訓練；方法目前是 gate + temporal attention + smooth 三個模組並列，敘事單薄。

**判斷**：重投影 loss 失效是**結構性的**，不是調參問題。重投影殘差對平移誤差的敏感度由視差決定，低視差時梯度不帶資訊（此因果鏈已量測過，結論與目標無關，含 L_ego_flow）。若醫學影像是內視鏡／腹腔鏡（低視差），同一限制會再命中一次 → **不要再投入時間換另一種重投影變體**。

**重新框架**：不要數模組，要把 gate 講成**一個機制、兩個入口**：
1. 推論時 —— attention bias，camera token 只聚合靜態 patch（現況）
2. 訓練時 —— gate 定義一個輔助任務，把「相機不該看動態區域」從架構偏好變成可優化的約束（**目前缺的就是這個**）

溫和地說，temporal attention 與 smooth 應退回 ablation table 的位置，不要當 contribution 撐場面。

### 主提案：gate-conditioned invariance loss
兩次 forward：原圖 vs 把 σ(g) 高的 patch 內容擾動掉（雜訊／模糊／鄰域填補），要求 pose 預測一致。

適配三個現有困境：
- **不依賴視差** —— 兩次 forward 間的相對約束，非幾何殘差，低視差不會讓訊號消失
- **不需要 mask GT** —— 純自監督，直接解掉醫學影像無標籤問題；這就是 gate 策略 **C 方案的具體形式**
- **是 gate 的功能性定義** —— gate = 「使 pose 對動態內容不變的那個東西」，論文敘事遠強於「我們加了一個 gate」

**⚠️ 必須處理的退化解**：若 gate 學會輸出「全部靜態」，擾動集合為空 → 兩次 forward 相同 → loss 歸零。它會找到這個捷徑。
- **擋法（傾向）**：自然影像保留 BCE 錨定（有標籤，防 collapse）+ 醫學影像用 invariance（無標籤）。剛好對應 curriculum。
- **替代擋法**：雙向約束 —— 擾動動態區 → pose 不變；擾動等面積隨機靜態區 → pose 應受影響。

### 備案
- **靜態區 3D 剛性殘差**：3D-to-3D 約束，較不吃視差，但會被 depth 誤差污染
- **gate 時間一致性**：σ(g) 沿 flow warp 後幀間一致；便宜但只有正則項等級，撐不起 contribution
