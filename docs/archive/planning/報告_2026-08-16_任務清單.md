## 🎞️ GIF 的兩種可能（需確認）

「推動模型的 gif」有兩種解讀，成本差很多：

1. **3D 轉盤動畫**（點雲繞軸旋轉）—— 最能展示「重構」品質。已有 PLY export 可接，成本中等。
2. **逐幀序列播放**（時間軸推進）—— 展示 sequence 模式的時序一致性。成本低。

> **建議兩種都做**，因為它們論證的是不同的事：轉盤證明**幾何重構好**，逐幀證明**序列穩定**。而 A1 的賣點正是 pair→sequence，逐幀動畫直接對應這個賣點。若只能選一個，A1 選**逐幀**，A2/A4 選**轉盤**。

## 📊 B 項：smooth 的 2×2 消融設計

要「分開對比訓練 vs TTO」，乾淨的做法是 2×2，而不是兩組獨立比較：

| | **TTO 無 smooth** | **TTO 有 smooth** |
|---|---|---|
| **訓練無 smooth** | baseline | 只有 TTO 的貢獻 |
| **訓練有 smooth** | 只有訓練的貢獻 | 兩者疊加 |

這樣才能回答三個問題：訓練時的 smooth 有沒有用、TTO 時的 smooth 有沒有用、**兩者是疊加還是互相取代**。第三題是最有價值的——如果 TTO 的 smooth 能取代訓練時的 smooth，那方法可以簡化；如果互補，那是一個賣點。

**執行策略**：
1. **先撈既有結果**填格子（`logs/` 與 `outputs/` 裡已有 `_smooth` / `_temporal` 系列的 run）
2. 缺的格子才補跑，**優先補 TTO 那兩格**（TTO 不需要重新訓練，成本遠低於重訓）
3. 一格都補不齊時 → 降級成「只報訓練時的效果」，並在報告中明說 TTO 對比尚未完成
