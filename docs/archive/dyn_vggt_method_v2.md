## 0. TL;DR

> v1 把動態幾何寫成 `X = X^can + m·Δ`，用乘積把「靜態正則點」和「動態位移」組裝起來。但這個乘積在數學上**不可辨識**（`m`、`Δ` 無限多種拆法），且動態區 `X^can` 無監督而成為**偷懶捷徑**，導致 `Δ` 永遠學不起來（已由診斷證實：即使 mask 準，靜態/動態 `Δ` 也不分離）。

## 1. 為何要從 v1 改版：雙場的架構級缺陷

### 1.1 v1 的設計
v1 對每個像素輸出 `X = X^can + m·Δ`：`X^can`（剛性正則點，沿用 point 頭）、`m`（動態機率）、`Δ`（殘差位移，flow 頭）。dense flow loss 監督**組裝後的和** `X` 對 GT `world_points`；`L_point` 在動態區用 `(1−m)` 屏蔽 `X^can`。

### 1.2 兩個致命機制（已由診斷實證）
**機制一：`m × Δ` 是雙線性項，無法分別決定。**
只監督「相加後結果」時，`m·Δ = r` 有無限多組解（`(c·m, Δ/c)` 等價）。`Δ` 沒有自己的目標，只能隨乘積飄。

**機制二：動態區 `X^can` 無監督 → 偷懶捷徑。**
`(1−m)` 屏蔽關掉了動態區對 `X^can` 的監督 → `X^can` 變自由變量。網絡要湊出動態物體位置時，走「強預訓練的 point 頭（`X^can`，梯度完整）」比走「隨機初始化的 flow 頭（`Δ`，梯度被 `m<1` 縮放）」容易得多 → **運動被塞進 `X^can`，`Δ` 閒置 ≈ 0**。

### 1.3 診斷證據
跨 stage、跨域（PointOdyssey / Sintel）診斷：
- **Δ 不分離**：動態/靜態 `Δ` 中位數比值 0.77–1.16（理想應 ≫ 1）。**即使在 PO 上 mask 已很準（AUC≈0.88），Δ 仍不分離** → 證明這不是 mask 不好（訓練問題），而是目標函數病態（**架構問題**）。
- mask 頭本身在訓練域（PO）AUC≈0.88、跨到 Sintel 塌到 ≈0.45 → 那是**獨立的 domain-gap（數據）問題**，與雙場病態無關，需各自處理。

> **結論**：雙場的幾何組裝方式必須換掉。加再多數據、調再多權重都無法改變病態目標函數偏好的偷懶解。
