## 0. 共同設定

- **資料**：SCARED test/pose 兩條連續序列，`dataset3/keyframe4`（ds3，834 幀）、`dataset5/keyframe4`（ds5，411 幀）。
- **指標**：snippet ATE（5 幀滑動窗，AF-SfMLearner 協定），越小越好。表中「平均」是兩條序列的平均。
- **協定**：c64 = `--chunk_size 64 --overlap 16`（18 / 9 個 chunk）；c5 = `--chunk_size 5 --overlap 4`（830 / 407 個窗）。
- **ckpt**：`tfs` = `logs/scared_cam_depth_tfs/ckpts/epoch_10.pt`；`VGGT-1B` = `checkpoints/VGGT-1B.pt`。
- **遮罩只在推論時套用**，權重不變。四種遮法：

| 代號 | CLI | 誰被限制 |
|---|---|---|
| M1 | `--mask_mode camera` | camera / register token 不看標 1 的 patch（現有 gate 的路徑，bias −30） |
| M2 | `--mask_mode all` | 所有 token 都不看標 1 的 patch（實作為把那些 key / value 拿掉） |
| M3 | `--mask_mode cross` | 所有 token 都不看**其他幀**裡標 1 的 patch（flex_attention，bias −30） |
| T | `--mask_temporal` | temporal block 裡，每個位置不看其他幀在同位置標 1 的 patch（bias −30） |

- **起始層**：`--mask_start k`，從第 k 個 aa-block 起遮（global 與 temporal 共用）。步驟 0 固定 8。
- 所有 eval 的 `failed_seqs` 都是空的。

## 1. 極線標籤

## 4. 沒做的與限制

- **depth 多張**沒有跑（test/depth 的標籤沒過檢查）。
- 步驟 0 的 M3 在 c5 的兩個數字（0.0910、0.0914）：「起始層 8、原始影像」這個設定沒有做遮罩全 0 的檢查；同一個 kernel 在 §3.6 的設定下有過。
- 全部單一 seed 的 ckpt；正控制是單一貼片、單一種子、只有 `tfs`。
- 極線標籤、貼干擾物、隨機遮罩、彙整的 script 都在這次 session 的 scratchpad，沒有進 repo。
- 這台的 torch 是 2.8.0+cu128。M3 的 flex kernel 用預設 block 大小編譯失敗，改用 32×32。
